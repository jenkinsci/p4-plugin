A command that runs only the tests that were failing, so a fix that does not actually fix them is rejected without waiting for a full build. {tests} is replaced with their comma-separated ids.

Leave it blank to use this job's own build step. The job's Invoke top-level Maven targets step is read, and its goals are replaced with test -Dtest={tests}.

Only a Maven build step can be read. If this job builds with a shell script or a batch file, either fill this in yourself or leave it blank to skip the targeted run — the full build still decides whether a fix is real.

The full build itself is never configured here. It is always the command this job's build step runs, so a fix is proved against the build that failed.
